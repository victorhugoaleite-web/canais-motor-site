Política de privacidade do canais-motor

Atualizada em 2 de novembro de 2026.

O canais-motor é uma ferramenta pessoal, usada só pelo autor para gerenciar os próprios canais no YouTube. Ela roda no computador do autor e não tem usuários externos.

Quais dados acessa

Com a autorização da conta Google do canal, a ferramenta usa os serviços de API do YouTube para:

  • enviar vídeos, miniaturas e legendas e definir título, descrição, privacidade e data de publicação;
  • atualizar a arte e a descrição do canal;
  • ler estatísticas do canal e dos vídeos (visualizações, tempo assistido e curva de retenção) pela YouTube Analytics API.

Como guarda e usa

O token de acesso e as estatísticas ficam só no computador do autor. Os dados servem apenas para publicar os vídeos e comparar o desempenho entre eles. Nada é vendido, compartilhado com terceiros nem usado para publicidade. O uso dos dados segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Termos do YouTube e do Google

Ao usar a ferramenta, valem os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Como revogar o acesso

O acesso pode ser removido a qualquer momento em myaccount.google.com/permissions. Os dados guardados localmente são apagados quando o autor para de usar a ferramenta.

canais-motor privacy policy

Updated November 2, 2026.

canais-motor is a personal tool, used only by its author to manage the author's own YouTube channels. It runs on the author's computer and has no outside users.

Data accessed. With the channel's Google account authorization, it uses YouTube API Services to upload videos, thumbnails and captions and set their title, description, privacy and publish time; to update the channel art and description; and to read channel and video statistics (views, watch time and audience retention) through the YouTube Analytics API.

Storage and use. The access token and statistics are kept only on the author's computer and are used only to publish videos and compare their performance. Nothing is sold, shared with third parties or used for advertising. Use of this data complies with the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google terms. Using the tool means agreeing to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access. Access can be removed at any time at myaccount.google.com/permissions. Locally stored data is deleted when the author stops using the tool.
